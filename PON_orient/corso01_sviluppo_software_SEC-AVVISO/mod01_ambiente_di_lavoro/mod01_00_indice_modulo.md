# Modulo 1: Ambiente di lavoro

Durata: 2 ore (lezioni 1.1 e 1.2).

Obiettivi del modulo:

- distinguere i principali tipi di linguaggi di programmazione e il modo in cui un programma viene eseguito
- conoscere gli strumenti di lavoro quotidiani di uno sviluppatore
- predisporre sul proprio PC un ambiente di sviluppo completo, portatile e gratuito
- usare il terminale e registrare il proprio lavoro con Git

Fonti: la lezione 1.1 è un adattamento della lezione 01 del corso Microsoft "Web Development for Beginners" (licenza MIT), con attribuzione completa nel file della lezione; la lezione 1.2 è un contenuto originale.

## Lezioni

| Lezione | Titolo | Directory |
|---|---|---|
| 1.1 | Programmi, linguaggi e strumenti del mestiere | `lez01_programmi_linguaggi_strumenti/` |
| 1.2 | Terminale e controllo di versione con Git | `lez02_terminale_e_git/` |

Ogni directory di lezione contiene tre file con lo stesso prefisso: la lezione (`.md`), la presentazione Marp (`_marp.md`) e la presentazione pandoc reveal.js (`_prezpdoc.md`).
