# Modulo 4: HTML e CSS

Durata: 4 ore (lezioni 4.1-4.4).

Obiettivi del modulo:

- scrivere pagine HTML corrette e ben strutturate
- usare gli elementi semantici e applicare i principi di base dell'accessibilità
- applicare stili con il CSS: selettori, cascata, ereditarietà, box model
- impaginare con il posizionamento e con Flexbox, e realizzare pagine responsive
- verificare il proprio lavoro con validatore, strumenti per sviluppatori e strumenti di accessibilità

Prerequisiti: modulo 1 (ambiente di lavoro, Live Preview, Git).

Progetto del modulo: il **terrario virtuale**, ripreso nel modulo 5 per il trascinamento delle piante con JavaScript.

Fonti: le lezioni sono adattamenti delle lezioni 03, 08 e 09 del corso Microsoft "Web Development for Beginners" (licenza MIT), con attribuzione completa nei file delle lezioni; le sezioni su Flexbox e pagine responsive sono contenuto originale. Le immagini delle piante provengono dallo stesso repository Microsoft.
