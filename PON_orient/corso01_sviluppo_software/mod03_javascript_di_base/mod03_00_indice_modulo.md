# Modulo 3: JavaScript di base

Durata: 6 ore (lezioni 3.1-3.6).

Obiettivi del modulo:

- dichiarare variabili e costanti e usare i tipi di dato principali di JavaScript
- scrivere funzioni con parametri e valore di ritorno, comprese le funzioni freccia e le callback
- controllare il flusso del programma con condizioni, `switch` e operatore ternario
- elaborare elenchi di dati con array e cicli
- tradurre in codice gli algoritmi del modulo 2 e verificarli con test automatici
- riconoscere i tipi di errore e usare console e debugger del browser con metodo

Prerequisiti: moduli 1 e 2 (ambiente di lavoro, pseudocodice, algoritmi su elenchi).

Fonti: le lezioni 3.1-3.4 sono adattamenti delle lezioni 04-07 del corso Microsoft "Web Development for Beginners" (licenza MIT), con attribuzione completa nei file delle lezioni; le lezioni 3.5 e 3.6 sono contenuti originali. Riferimenti MDN solo tramite link.
