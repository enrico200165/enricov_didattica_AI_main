# Lezione 6.1: soluzioni dell'attività di classificazione

| N. | Servizio | Cloud | Modello | Note |
|---|---|---|---|---|
| 1 | Posta della scuola dal browser | sì | SaaS | il fornitore aggiorna il programma; la scuola gestisce account, password, dati |
| 2 | Registro elettronico | sì | SaaS | la scuola resta titolare dei dati degli studenti e gestisce gli accessi |
| 3 | Macchina virtuale noleggiata | sì | IaaS | aggiornamenti del sistema operativo e del servizio a carico della scuola |
| 4 | Database gestito | sì | PaaS (DBaaS) | il fornitore aggiorna e fa le copie di sicurezza secondo le impostazioni; la scuola progetta tabelle, dati, permessi |
| 5 | Archiviazione a oggetti | sì | PaaS (o STaaS; alcuni lo considerano IaaS) | la scuola decide che cosa è pubblico e che cosa privato |
| 6 | Foglio di calcolo installato | no | software locale | se salva i file in un servizio online, quella parte è SaaS |
| 7 | Videochiamate online | sì | SaaS | |
| 8 | Server della scuola | no | server locale | mancano servizio su richiesta, elasticità, servizio misurato |
| 9 | Esecuzione di codice senza gestire server | sì | PaaS (FaaS, serverless) | |
| 10 | Sincronizzazione delle foto | sì | SaaS | dati personali in un servizio esterno: dove sono conservati? |

Domanda 3 (biblioteca): IaaS dà controllo completo ma richiede aggiornamenti e sicurezza del sistema operativo; PaaS riduce il lavoro di gestione e scala in automatico, ma lega di più al fornitore e costa di più per unità di risorsa. Per una scuola senza sistemisti dedicati il PaaS è in genere la scelta più semplice.
