# Stage: sviluppatore Python junior

Azienda di fantasia, annuncio creato per il corso.

Alfa Gestionali, software house di Roma con 40 dipendenti, cerca uno stagista per il team che sviluppa un'applicazione di prenotazione delle sale per le aziende.

## Attività

- sviluppo di nuove funzionalità in Python con il supporto di un tutor
- scrittura dei test automatici
- partecipazione alle riunioni Scrum del team

## Requisiti

- Diploma tecnico in informatica (anche in corso) o percorso equivalente
- Conoscenza di base di Python
- Uso di Git
- Conoscenza dei test automatici
- Inglese tecnico (lettura della documentazione)
- Capacità di lavorare in team e di comunicare con i colleghi

## Requisiti graditi

- Conoscenza di SQL e delle basi di dati
- Esperienza con framework web

## Offriamo

Stage di 3 mesi con rimborso spese, sede a Roma, possibilità di inserimento.
