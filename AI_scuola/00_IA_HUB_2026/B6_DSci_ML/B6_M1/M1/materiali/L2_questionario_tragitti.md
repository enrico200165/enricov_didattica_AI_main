# Scheda L2 - Questionario sui tragitti casa-scuola

## Domanda di ricerca

Quanto tempo impiegano gli studenti ad arrivare a scuola, e da che cosa dipende?

## Regole della raccolta

- il questionario è anonimo: nessun nome, email, indirizzo, data di nascita
- nessuna domanda è obbligatoria
- si risponde pensando a un giorno tipico, non a un giorno particolare

## Questionario (bozza da completare in classe)

1. Anno di corso
   ( ) 3   ( ) 4   ( ) 5
2. Mezzo di trasporto principale (quello su cui passi più tempo)
   ( ) a piedi   ( ) bicicletta   ( ) monopattino   ( ) autobus   ( ) auto   ( ) treno
3. Distanza tra casa e scuola, in chilometri, con una cifra decimale (per esempio 3,5): ________ km
4. Tempo impiegato di solito, in minuti, dall'uscita di casa all'ingresso a scuola: ________ minuti
5. Ora in cui esci di casa
   ( ) prima delle 7:00   ( ) 7:00-7:30   ( ) 7:30-7:45   ( ) dopo le 7:45
6. Variabile aggiunta dalla classe (facoltativa): ______________________________

Come stimare la distanza: con una mappa online, percorso dalla propria via alla scuola (non serve l'indirizzo esatto e non va scritto da nessuna parte).
